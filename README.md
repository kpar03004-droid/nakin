# 📒 낙인 (Nakin) — 동글랜드 냥 가계부

"오늘 사냥·장사로 얼마 벌었지? 강화에 얼마 썼지?"
**낙인**은 동글랜드에서 번 냥과 쓴 냥을 **알아서 기록하고 정리해 주는 가계부 모드**입니다. 따로 적을 필요 없이 평소처럼 플레이하면 됩니다.

> 🔒 **안심하고 쓰세요** — 화면에 이미 보이는 **내 냥 잔고**와 **나에게 온 거래 알림**만 읽습니다.
> 서버로 아무것도 보내지 않고, 대신 클릭하거나 행동하지 않습니다. 동글랜드 운영진의 기능 검토를 통과한 모드입니다.

## ✨ 이런 걸 해 줍니다
- **실시간 HUD** — 오늘 수입·지출·순이익과 많이 번 항목을 화면 한쪽에 표시 (위치·크기·투명도 조절)
- **정산 창** `/낙인` — 오늘 / 주간 그래프 / 거래 내역(클릭해서 수정) / 직접 기록 / 설정
- **통계** — 기간별·분야별 수입·지출, 품목별 내역
- **잔고 대조** — 기록에 없는 잔고 변동을 알려 줌 · 정산 복사(Ctrl+C)
- **자동 분류**
  - 직업별 NPC 판매: 대장장이 · 농부 · 요리사 · 연금술사 · 다이버 · 낚시
  - 유저 거래: 거래소 · 플리마켓 · 송금 · 직거래
  - 지출: NPC 상점(산 물건 이름까지) · 인챈트 · 생활장비 강화 · 전직 · 유물 감정 · 카드팩 · 워프 · 마을 금고
  - 보상: 보스 · 이벤트 · 길라잡이 · 우편함(추천·출석) · 동글 패스
- **수수료 반영** — 송금·직거래 3%, 플리마켓 5%, 거래소 7%를 뺀 실제 받은 금액으로 기록
- **잔고 교차 확인** — 알림 금액과 실제 잔고 변화가 맞는지 대조하고, 금액이 안 나오는 거래(강화·감정 등)는 잔고 변화로 금액을 잡습니다
- **엑셀·CSV 내보내기** `/낙인 내보내기`

## 📥 설치
1. [**최신 릴리즈**](https://github.com/kpar03004-droid/nakin/releases/latest) 에서 `nakin-fabric-<버전>.jar` 를 받습니다.
2. mods 폴더에 넣습니다.
   - 동글랜드 공식 설치 프로그램을 쓰면 `.minecraft/modcheck/mods`
3. 게임을 **완전히 종료한 뒤** 다시 실행합니다.

**필요한 것:** Minecraft 26.1.2 · Fabric Loader 0.19.0 이상 · Fabric API (공식 설치 프로그램에 포함)
**선택:** YetAnotherConfigLib — 있으면 설정 화면이 열립니다.

## ⌨️ 명령어 (영문 `/nakin` 도 같음)
| 명령 | 하는 일 |
|---|---|
| `/낙인` | 정산 창 열기 |
| `/낙인 오늘` · `/낙인 주간` | 채팅으로 요약 보기 |
| `/낙인 위치` | HUD 위치·크기 편집 (드래그) |
| `/낙인 표시` | HUD 켜기/끄기 |
| `/낙인 추가 수입\|지출 <금액> [설명]` | 빠진 거래 직접 기록 |
| `/낙인 내보내기` | 이번 달 기록을 엑셀·CSV로 저장 |
| `/낙인 진단` | 인식 상태 확인 (문제 제보할 때 필요) |
| `/낙인 제보` | 제보용 기록을 클립보드에 복사 + 제보 폼 링크 |
| `/낙인 업데이트` | 새 버전 받기 |

단축키는 `옵션 → 조작 → 키 설정 → 낙인` 에서 지정할 수 있습니다(기본값 없음).

## ❓ 잘못 기록됐다면
1. `/낙인` → **내역** 탭에서 잘못된 줄을 **Shift+클릭**해서 지웁니다.
2. `/낙인 추가 지출 <금액> <설명>` (또는 수입) 으로 다시 넣습니다.
3. 계속 틀리면 [**건의·버그 제보 폼**](https://forms.gle/4PifTzDVemPqjPQN7)에 해당 채팅 문구와 `/낙인 진단` 결과를 남겨 주세요. 서버 문구가 바뀌면 인식이 안 될 수 있어 바로 고치겠습니다.

💬 **건의·버그 제보:** https://forms.gle/4PifTzDVemPqjPQN7

## 🔄 업데이트
새 버전이 나오면 게임 안에 알림이 뜹니다. `/낙인 업데이트` 에서 동의하면 받아 두었다가 게임을 끌 때 교체합니다.
직접 바꿀 때는 이전 `nakin-fabric-…jar` 를 **지우고** 새 파일을 넣으세요(둘 다 있으면 충돌). 기록과 설정은 그대로 남습니다.
