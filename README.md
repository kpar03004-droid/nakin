# 낙인 (Nakin)

동글랜드에서 오늘 번 냥과 쓴 냥을 자동으로 정리해 주는 **클라이언트 전용 가계부 모드**입니다.

화면에 이미 보이는 **내 냥 잔고**와 **나에게 온 거래 채팅**만 읽습니다.
서버로 아무것도 보내지 않고, 어떤 행동도 대신하지 않습니다.

- 오늘 수입·지출·순익 HUD (위치·크기·투명도 조절)
- 정산 창: 오늘 / 주간 / 거래 내역 / 수동 기록 / 설정
- 카테고리 자동 분류: 직업별 NPC 판매(대장장이·농부·요리사·연금술사·다이버·낚시), 거래소, 플리마켓, 송금, 직거래, 마을 금고, 인챈트·강화·전직 등
- 엑셀(.xlsx)·CSV 내보내기

## 설치
- Minecraft **26.1.2**, Fabric Loader 0.19.0 이상
- 필수: Fabric API / 선택: YetAnotherConfigLib(설정 화면)
- [Releases](https://github.com/kpar03004-droid/nakin/releases/latest) 에서 `nakin-fabric-<버전>.jar` 를 받아 mods 폴더에 넣습니다.
  - 동글랜드 공식 설치 프로그램 사용 시: `.minecraft/modcheck/mods`

## 업데이트
새 버전이 나오면 게임 안에 알림이 뜹니다. `/낙인 업데이트` 에서 동의하면 받아 두었다가 게임을 끌 때 교체합니다.
직접 바꿀 때는 이전 `nakin-fabric-…jar` 를 **지우고** 새 파일을 넣으세요(둘 다 있으면 충돌). 기록과 설정은 그대로 남습니다.
