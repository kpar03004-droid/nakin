# 낙인 사용 설명서

오늘 번 냥과 쓴 냥을 자동으로 정리해 주는 가계부 모드입니다.

## 설치
1. `nakin-fabric-<버전>.jar`를 mods 폴더에 넣습니다.
   - 동글랜드 공식 설치 프로그램을 쓰면 `.minecraft/modcheck/mods`
2. 게임을 완전히 껐다가 다시 켭니다.
3. 필요한 것: Fabric API(동글랜드 설치 프로그램에 이미 들어 있음).
   - 설정 화면을 쓰려면 YetAnotherConfigLib가 있어야 합니다.

> 새 버전으로 바꿀 때는 **이전 `nakin-fabric-…jar`를 지우고** 새 파일을 넣으세요. 두 개가 같이 있으면 충돌합니다. 기록과 설정은 그대로 남습니다.

## 화면
- **HUD**: 오늘 순익·수입·지출과 많이 번 카테고리가 표시됩니다.
  - `/낙인 위치`: 드래그로 옮기기, 모서리를 잡고 크기 조절, 방향키로 1칸씩 이동
  - `/낙인 표시`: HUD 켜기/끄기
- **정산 창** `/낙인`
  - 오늘: 수입·지출과 카테고리별 합계
  - 주간: 최근 7일 막대그래프
  - 내역: 오늘 거래 목록. **Shift+클릭으로 그 줄을 삭제**합니다.
  - 관리: 수동 기록 추가, 날짜별 초기화
  - 설정: HUD 위치, 투명도

## 명령어 (영문 `/nakin`도 똑같이 동작)
| 명령 | 내용 |
|---|---|
| `/낙인` | 정산 창 |
| `/낙인 오늘` · `/낙인 주간` | 채팅으로 요약 |
| `/낙인 날짜 2026-09-28` | 특정 날짜 요약 |
| `/낙인 추가 수입 <금액> [설명]` | 빠진 수입 직접 추가 |
| `/낙인 추가 지출 <금액> [설명]` | 빠진 지출 직접 추가 |
| `/낙인 내보내기` | 이번 달을 엑셀·CSV로 저장 (`week`, `today`, `2026-09`도 가능) |
| `/낙인 진단` | 금액이 이상할 때 이 결과를 스크린샷으로 보내 주세요 |
| `/낙인 초기화` | 오늘 기록 초기화 |
| `/낙인 테스트` | **싱글플레이 전용** 동작 확인 창. 버튼으로 동글랜드 거래 문구·잔고 변화를 흉내 냄(치트 불필요, 싱글 기록은 월드를 나가면 자동 삭제) |

## 이렇게 기록됩니다
- **NPC에게 판 돈**은 직업별로 묶입니다: 대장장이, 농부, 요리사, 연금술사, 다이버, 낚시. 모르는 품목은 "무역상점"으로 들어갑니다.
- **유저끼리 거래한 돈**은 창구별로 묶입니다: 거래소, 플리마켓, 송금, 직거래.
- **거래소** 대금은 광장에 있을 때만 들어옵니다. 광장에서 팔리면 그 알림으로, 마을에 있을 때 팔린 건 광장에 들어갈 때 뜨는 수령 알림으로 기록됩니다(수수료 7% 뺀 금액). 같은 판매가 겹쳐 알려져도 한 번만 셉니다.
- **송금**: 보낸 돈은 원금 전액, 받은 돈은 수수료 3%가 빠진 실수령액으로 기록됩니다.
- **마을 금고 입금**은 기본적으로 지출로 셉니다. 설정의 "마을 금고 입금을 이체로"를 켜면 손익에서 빠집니다.
- **생활장비 강화**는 대장간 창에 적힌 비용(예: 120000원)만큼 잔고가 줄면 기록됩니다. 성공·실패·하락 모두 잡힙니다.
- **무역 카드팩 뒤집기**는 유료인 장(예: 2장째 3만, 3장째 10만)만 지출로 잡힙니다. 무료 장과 VIP·VVIP 할인은 자동으로 반영됩니다. **유물 감정**은 1,000냥으로 잡힙니다.
- **모루 인챈트·전직**은 채팅에 금액이 안 나와서, 성공 문구 직후 잔고가 줄어든 양으로 기록됩니다.
  - 금액을 못 찾으면 내역에 **"미확인"**으로 남고 채팅으로 알려드립니다. `/낙인 추가 지출 <금액>`으로 넣고, 미확인 줄은 Shift+클릭으로 지우세요.

## 잘못 기록됐을 때
1. `/낙인` → 내역 탭에서 잘못된 줄을 **Shift+클릭**해서 지웁니다.
2. `/낙인 추가 지출 <금액> <설명>`(또는 수입)으로 바르게 다시 넣습니다.
3. 반복되면 채팅 스크린샷과 `/낙인 진단` 결과를 보내 주세요.
